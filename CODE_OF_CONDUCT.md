# Code of conduct

pyskins is a small, friendly project, and a child may read it. Please help us keep it that way.

- Be kind and patient. Everyone was a beginner once.
- Talk about the code and the ideas, not about the person.
- No insults, no harassment, nothing rude or scary. This goes for issues, pull requests, skins and example programs.

If someone breaks these rules, tell the maintainers privately with [this form](https://github.com/AlexandruGirlea/pyskins/security/advisories/new). We may edit or remove what was posted, and block people who keep doing it.

These rules follow the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
